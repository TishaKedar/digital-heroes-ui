# Digital Heroes frontend prototype

## Build
- Establish a premium rewards-and-impact visual system using off-white, navy, blue, and restrained violet accents.
- Add shared public and application navigation, buttons, cards, inputs, status indicators, and responsive shells.
- Create dedicated routes for the landing, login, signup, subscriber dashboard, charities, draw, and admin screens.
- Use realistic in-memory sample data and client-side interactions only, including score editing, filters, tabs, and draw simulation.
- Add unique page metadata and keep every screen fully frontend-only.

## Technical details
- Preserve the existing TanStack Start and Tailwind setup.
- Reuse the project’s interface primitives and Lucide icons.
- Do not add Cloud, databases, authentication, payments, APIs, or server functions.
- Validate all routes at desktop and mobile sizes in the live preview.
