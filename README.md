# Digital Heroes UI

Design and build ONLY the frontend UI for a web application called "Digital Heroes".

Do NOT create or modify any backend, database, authentication, Supabase tables, APIs, Stripe integration, or server-side functionality.

This is a UI prototype that we will connect to our own React + Supabase application later.

Digital Heroes is a modern subscription-based platform combining:

- Golf performance tracking

- Monthly prize draws

- Charity fundraising

DESIGN DIRECTION:

Create a premium, modern SaaS/fintech-style interface.

Use:

- White/off-white backgrounds

- Deep navy text

- Soft blue and subtle purple accents

- Elegant gradients

- Rounded cards

- Large modern typography

- Generous whitespace

- Subtle animations and micro-interactions

- Responsive desktop/tablet/mobile layouts

Avoid:

- Traditional golf website aesthetics

- Golf clubs as major imagery

- Plaid

- Generic golf-course hero images

- Overly sporty or childish design

The visual identity should feel like a premium rewards + social-impact platform.

CREATE THESE UI SCREENS:

1. LANDING PAGE

- Navbar

- Hero

- How It Works

- Monthly Draw explanation

- Charity Impact section

- Featured Charity

- Subscribe CTA

- Footer

Hero headline:

"Play your game. Create an impact."

2. LOGIN PAGE

- Email

- Password

- Login button

- Forgot password

- Link to signup

3. SIGNUP PAGE

- Name

- Email

- Password

- Charity selection

- Contribution percentage

- Signup CTA

4. SUBSCRIBER DASHBOARD

Create a polished dashboard UI containing:

- Subscription status

- Renewal date

- Latest 5 Stableford scores

- Add/edit/delete score UI

- Selected charity

- Charity contribution percentage

- Upcoming draw

- Draw participation

- Winnings

- Payment status

5. CHARITIES PAGE

- Search

- Filters

- Charity cards

- Featured charity

- Charity details

6. DRAW PAGE

- Current monthly draw

- 3-number match

- 4-number match

- 5-number jackpot

- Previous draws

- Winning numbers

7. ADMIN DASHBOARD

Create the UI only for:

- Overview analytics

- User management

- Draw management

- Draw simulation

- Charity management

- Winner verification

- Payout management

Use reusable components and consistent spacing, typography, cards, buttons and navigation.

Use realistic sample data purely for visual purposes.

IMPORTANT:

This is UI ONLY.

Do not create a backend.

Do not create database tables.

Do not connect Supabase.

Do not implement authentication.

Do not implement Stripe.

Do not implement APIs.

The final UI should look like a polished production application even though the data is currently mock data.
